# 更新履歴

## 0.0.6

- circleの楕円・円弧オプションとpath.offsetの補完・ホバー説明に対応。
- 楕円・円弧・楕円弧の直接描画／パス作成とオフセットのスニペットを7種類追加。
- 部分円弧の塗り・合成制限、drawのスタイル上書き説明を更新。
- 最新exeで新API、SVG / DXF書き出し、プレビュー更新を検証。

## 0.0.5

- すべてのコマンド表示名とスニペット名を英語へ統一。
- 実行ファイル選択・書き出しダイアログ、進行表示、プレビューのタイトルを英語へ変更。
- コマンド識別子・設定キー・スニペットの入力プレフィックスは維持。

## 0.0.4

- 「ZFJ: 拡張子の登録」「ZFJ: 拡張子登録の削除」を追加。
- 設定したzfj.exeの--install / --uninstallを入力ファイルなしで呼び出し。
- ファイル未表示時のexe選択、実行結果の通知・ログ、エラー処理、二重実行防止に対応。
- 登録コマンドのテストはプロセス起動を模擬し、Windowsの関連付けを変更しない。

## 0.0.3

- drawing.polyline・path.polylineによる開いた折れ線の補完・説明を追加。
- drawing.regularPolygon・drawing.starの直接描画に対応。
- path.move・path.movedと、パス変数・同一行の連結呼び出しでのmove/moved補完・説明を追加。
- 新API用スニペットを8種類追加。既存スニペットは維持。
- 最新のzfj.exeでAPI・スニペット74件、SVG / DXF書き出し14件、プレビュー生成・更新を検証。

## 0.0.2

- path APIの10関数とdrawing.draw、互換用drawing.combineの補完・ホバー説明に対応。
- SVG表示合成、Clipper2合成、変換、正多角形、星型などのスニペットを追加。
- 既存の関数呼び出しを補完する際に括弧・引数が重複しないよう修正。
- 更新されたzfj.exeでSVG / DXFの書き出しとSVGプレビュー生成を検証。

## 0.0.1

- drawing APIの補完、色分け、スニペット。
- SVG / DXF書き出しと保存時に更新するSVGプレビュー。
